01Tổng quan repo

nsac-data KHÔNG phải product code. Đây là "xưởng dữ liệu": copy dữ liệu analog công khai (mặt đất + ISS), chuẩn hóa, train mô hình, đánh giá trung thực (out-of-fold), rồi xuất dự đoán + catalog để web nsac đọc. Code product nằm ở apps/web và apps/backend của repo cha.

Vai trò

Xưởng dữ liệu

Copy → verify SHA-256 → features → train → evaluate → predict. Mọi bước chạy lại được, mọi file có data card + sha256.

Mục tiêu round 1

Reproduction

Metrics phải khớp run NASA-cl 11/11 (MAE/macro-F1 trong 1e-6; sleep 0.005). Đã đạt — xem mục Kết quả.

Đối tượng dùng

Web nsac agent

Agent TypeScript/Bun/Drizzle đọc CSV/JSON. KHÔNG nạp .joblib, KHÔNG gán dữ liệu analog cho 6 phi hành gia hư cấu.

Trạng thái

6/6 CHỈ SỐ — 3 CÓ, 3 CHƯA

HR, sleep (một phần), CPET, dose có. BP, nhiệt độ, tâm trạng, glucose: chưa có dữ liệu.

02Pipeline sky-ml — 5 bước, module đánh số theo thứ tự chạy

Module bước bắt đầu bằng chữ số (1_load_data.py…), module hỗ trợ bắt đầu bằng _. Module có chữ số đầu không import trực tiếp được — load qua sky_ml._steps (importlib). Cấu hình YAML, không phải TOML/Python.

BƯỚC 1

load-data

Copy allowlist từ NASA-cl (chỉ đọc) → data/1_source/, verify SHA-256, ghi COPY_MANIFEST.csv.

sky-ml load-data
→
BƯỚC 2

build-features

Đọc configs/tasks.yaml → builder theo task → cửa sổ past→future (không leakage) → table.csv.gz + features.json + snapshot.json + data card.

sky-ml build-features <task>
→
BƯỚC 3

train

Fold LOSO / by_month; fit MỌI model trên cùng fold; lưu final.joblib (fit toàn bộ → người mới) + oof.csv.gz (out-of-fold).

sky-ml train <task>
→
BƯỚC 4

evaluate

Per-fold metrics, bootstrap CI95 theo người (10.000 mẫu), so với baseline, permutation test, interval coverage (conformal 90%).

sky-ml evaluate <task>
→
BƯỚC 5

predict

Nạp model đã lưu, dự báo người mới. Abstain khi thiếu feature / ngoài range train. Cờ in_sample. Không cho chạy nếu features đổi từ lúc train.

sky-ml predict <task> --input X

Support modules _*.py

_settings · _runs · _datacards · _jsonio · _models · _artifacts · _hashing · _steps · _cli

Entry point: sky_ml._cli:main. Ruff rule N999 (tên file số) được ignore.

Nguyên tắc chống leakage

  • Cửa sổ đặc trưng chỉ nhìn quá khứ; target ở tương lai.
  • OOF: mỗi người được dự đoán bởi model chưa thấy họ.
  • Không gộp cohort (MMASH / UTMB / Sleep-EDF / RadLab) theo ID hay thời gian.
  • Metrics chỉ lấy từ OOF — không bao giờ in-sample.

Reproducibility

  • Seed 17 mọi task; snapshot.json ghi SHA-256 input, version thư viện, git rev.
  • Run id YYYY-MM-DD_HHMMSS, không bao giờ ghi đè run cũ.
  • data/CATALOG.csv: mỗi file một dòng, SHA-256 đầu ra.
  • Training trên Windows + PowerShell; Linux VM cần TZ=Asia/Bangkok.

07Hợp đồng dữ liệu cho web nsac (agent TypeScript/Bun/Drizzle)

Tóm tắt §2 của data/README.md — bắt buộc đọc trước khi dùng bất kỳ file nào. Vi phạm = hiển thị sai y khoa.

7.1 Thứ tự đọc

  1. Bảng CATALOG cuối data/README.md → lấy Run mới nhất + Dự đoán mới nhất của task.
  2. File dự đoán .csv (hiển thị) + .json cùng tên (thông số lần chạy).
  3. summary.json để hiển thị chất lượng model (MAE/F1 + CI95 theo người).
  4. Data card README.md từng thư mục khi cần nghĩa cột.

"Mới nhất" = run_id lớn nhất theo chuỗi; cùng run thì lấy hậu tố timestamp lớn nhất. Verify bằng SHA-256 trong CATALOG.

7.2 Cột file dự đoán (.csv)

CộtÝ nghĩa
subject_idvd. mmash:user_1 — KHÔNG phải phi hành gia
cutoff_timephút tương đối, KHÔNG đổi sang ngày/giờ thật
prediction + low90/high90giá trị + khoảng 90% (conformal)
abstain + reasonsTrue → hiển thị UNKNOWN, không nội suy
in_sampleTrue → nhãn "minh họa trên dữ liệu train"
y_true, abs_errorchỉ mode backtest

7.3 Quy tắc hiển thị (bắt buộc)

  • abstain=True → không hiển thị số; UNKNOWN + reasons.
  • Luôn hiển thị prediction kèm low90–high90 + đơn vị.
  • in_sample=True → gắn nhãn minh họa, không dùng làm bằng chứng chính xác.
  • Độ chính xác lấy từ summary.json, KHÔNG tự tính lại từ file dự đoán.
  • Không tự đặt ngưỡng cảnh báo — theo LOGIC_RA_QUYET_DINH, mỗi ngưỡng có nhãn bằng chứng.
  • Ghi nguồn khi hiển thị (MMASH ODbL · Sleep-EDF ODC-By · NASA NLSP · NASA OSDR).

7.4 KHÔNG làm

  • Không nạp .joblib trong web — pickle Python, có thể chạy mã tuỳ ý; TS không đọc được. Dự báo mới phải qua sky-ml predict.
  • Không gán mmash:user_N cho 6 phi hành gia hư cấu. configs/crew_map.yaml và bundle export-nsac v2 CHƯA xây.
  • Không gộp cohort theo ID/thời gian.
  • Không sửa file trong data/ bằng tay (kể cả phần CATALOG — sẽ bị ghi đè).

09Ràng buộc & việc còn lại

Ràng buộc cứng

  • Round 1 = reproduction; lệch thì dừng tìm nguyên nhân, không "cải tiến" trước.
  • Không merge cohort; không in-sample làm kết quả; không threshold thiếu nguồn.
